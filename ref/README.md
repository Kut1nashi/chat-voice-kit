# ref/ —— 参考音频放这里

`tts-core.cjs` 默认读取本目录下的 `reference.wav`（约 3~10 秒、单人、无 BGM、无混响）。
放一份同名 `.txt` 写上这段音频对应的原文，零样本克隆会明显更稳。

```
ref/reference.wav   你的参考音频
ref/reference.txt   它对应的原文（可选但强烈建议）
```

也可以换路径：`VOICE_TTS_REF=/path/to/your.wav`。

## ⚠️ 先确认你有权用这个音色

- ✅ 你自己的声音、你团队配音员签了授权的声音、明确允许二次使用的公开数据集音色。
- ❌ 配音演员 / 主播 / 歌手的声音克隆（本人未书面授权）——**这是声音人格权，属于典型的侵权高风险区**，哪怕只是发个模型权重也算。
- ❌ 从番剧、游戏、有声书、直播录像里切出来的音频——素材本身还有一层版权。

从音视频里切片可以用 `cutReference()`，降噪可以用 `separateVocals()`，
但**"技术上切得出来"不等于"法律上发得出去"**。

本目录的内容已被 `.gitignore` 忽略（`ref/*.wav`、`ref/*.txt`），
请确认它不会以别的方式被提交进仓库。
